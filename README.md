## [рус] ##

Небольшая утилита для настройки пунктов **классического ПКМ-меню** Windows 11.  
Также позволяет **включать/отключать** данное **меню**.

![Context Menu Cleaner](screenshots/ru.png)

## [eng]  ##

A lightweight utility for changing elements of the **classic Windows right-click context menu**.  
It also allows you to turn **on/off** this **menu**.

![Context Menu Cleaner](screenshots/en.png)
